# PDF маълумотнома → QR-код

Ҳар бир PDF файл учун алоҳида QR-код яратадиган содда веб-сайт.
QR сканер қилинганда — айнан ўша PDF браузерда очилади.

Сайт **иккига ажратилган**:

| Қисм | Файл | Ким киради |
|---|---|---|
| 🔐 **Админ** | `public/admin.html` | Фақат сиз — пароль билан. Юклаш, алмаштириш, ўчириш. |
| 📱 **Viewer** | `public/viewer.html` | Ҳамма — паролсиз. Фақат PDF кўринади, бошқа ҳеч нарса йўқ. |

Viewer саҳифада юклаш, ўчириш, рўйхат — ҳеч қайсиси йўқ. Одам QR сканер қилса,
тўғридан-тўғри ўша маълумотноманинг ўзини кўради.

## Қатор тушунчаси (муҳим)

Ҳар бир қатор — битта **уяча**: ўз ID'си ва ўз QR-коди бор.

- **Бўш қатор қўшиш** → QR дарҳол тайёр бўлади, PDF ҳали йўқ.
  QR-кодни босмага бериб, кейинроқ PDF юклашингиз мумкин.
- **PDF юклаш / PDF алмаштириш** → PDF ўша қаторга бириктирилади.
  **QR-код ўзгармайди** — босилган QR-кодлар ишлайверади.
- PDF ҳали юкланмаган QR сканер қилинса: "Маълумотнома ҳали юкланмаган" деб чиқади.

## Манзиллар (URL)

| Манзил | Вазифа | Пароль |
|---|---|---|
| `/` | Админ саҳифа | ✅ керак |
| `/api/files` | Рўйхат | ✅ керак |
| `/api/rows` | Бўш қатор қўшиш | ✅ керак |
| `/api/upload` | Бир нечта PDF бирдан юклаш | ✅ керак |
| `/api/files/:id/pdf` | Битта қаторга PDF юклаш/алмаштириш | ✅ керак |
| `/api/files/:id` | Номини ўзгартириш (PATCH), ўчириш (DELETE) | ✅ керак |
| `/p/:id` | **QR шу манзилга олиб боради** — PDF браузерда кўрсатилади | ❌ керак эмас |
| `/f/:id` | PDF файлнинг ўзи (`?download=1` — юклаб олиш) | ❌ керак эмас |
| `/qr/:id.png` | QR-код расми | ❌ керак эмас |
| `/healthz` | Текшириш | ❌ |

## PDF қандай кўрсатилади

`/p/:id` PDF файлни тўғридан-тўғри бермайди — ичида **PDF.js** кўрувчиси бўлган
саҳифани очади. Шунинг учун ҳар қандай телефонда (эски Android Chrome'да ҳам)
файл юкланмайди, браузернинг ўзида кўринади:

- юқорида **− / +** тугмалари билан катталаштириш;
- бармоқ билан ҳам катталаштириш мумкин;
- ўнгда **Юклаб олиш** тугмаси — истаган одам ўзи юклаб олади.

PDF.js файллари `pdfjs-dist` пакетидан `/vendor` орқали ўз серверимиздан
берилади — интернетдаги CDN'га боғлиқ эмас.

## Environment Variables (Railway'да)

| Ном | Қиймат | Изоҳ |
|---|---|---|
| `ADMIN_PASSWORD` | ўзингиз танлаган пароль | Админ саҳифа учун. **Албатта ўзгартиринг.** |
| `DATA_DIR` | `/data` | Volume уланган жой. PDF'лар шу ерда сақланади. |
| `PUBLIC_BASE_URL` | `https://sizning-domen.up.railway.app` | QR ичига ёзиладиган доимий манзил |

`PORT` ни ўзингиз қўшманг — Railway автоматик беради.

# Deploy қилиш — қадамма-қадам

## 1. GitHub repository яратиш

1. [github.com](https://github.com) га киринг → ўнг юқоридаги **+** → **New repository**.
2. Repository name: `pdf-qr`.
3. **Private** танланг (истасангиз Public).
4. README, .gitignore қўшманг — бизда бор.
5. **Create repository**.

## 2. Кодни GitHub'га жойлаш

Архивни компьютерга очинг, ўша папкада терминал очиб:

```bash
git init
git add .
git commit -m "PDF QR tizimi"
git branch -M main
git remote add origin https://github.com/FOYDALANUVCHI/pdf-qr.git
git push -u origin main
```

`FOYDALANUVCHI` ўрнига GitHub логинингизни ёзинг.

> Терминал ишлатмасангиз: GitHub'да repo ичида **Add file → Upload files** орқали ҳам барча файлларни (public папкаси билан бирга) юклаш мумкин.

## 3. Railway'га улаш

1. [railway.app](https://railway.app) → GitHub аккаунт билан киринг.
2. **New Project** → **Deploy from GitHub repo**.
3. `pdf-qr` репозиторийни танланг.
4. Railway ўзи `npm install` ва `npm start` ни ишга туширади.

## 4. Volume қўшиш (ЖУДА МУҲИМ)

Волюмсиз ҳар deploy'да PDF'лар ўчиб кетади.

1. Railway'да сервис устига босинг → **Variables** ёнидаги **Volumes** (ёки **+ Create → Volume**).
2. **Mount path**: `/data`
3. Сақланг.

## 5. Environment Variables созлаш

Сервис → **Variables** → **New Variable**:

```
ADMIN_PASSWORD = MahfiyParol2026
DATA_DIR = /data
```

`PUBLIC_BASE_URL` ни ҳозирча қўшманг — домен олингандан кейин қўшамиз.

## 6. Домен олиш

1. Сервис → **Settings** → **Networking** → **Generate Domain**.
2. Порт сўраса: `3000`.
3. Манзил чиқади, масалан: `https://pdf-qr-production-a1b2.up.railway.app`

Энди ўша манзилни **Variables** га қўшинг:

```
PUBLIC_BASE_URL = https://pdf-qr-production-a1b2.up.railway.app
```

Охиридаги `/` белгисиз. Railway ўзи қайта deploy қилади.

> Бу нима беради: QR-код ичига доим шу манзил ёзилади. Кейинчалик ўз доменингизни (масалан `qr.mening-saytim.uz`) уласангиз, фақат шу ўзгарувчини алмаштирасиз — эски QR-кодлар эса шу доменга уланиб туради.

## 7. Сайтни очиш ва текшириш

1. Браузерда доменни очинг.
2. Браузер пароль сўрайди:
   - **Username**: исталган сўз (масалан `admin`) — аҳамияти йўқ
   - **Password**: `ADMIN_PASSWORD` да ёзганингиз
3. Иккита йўлдан бири:
   - **Бир нечта PDF юклаш** → 5–10 та PDF танланг → ҳар бирига ўз қатори ва QR'и яратилади.
   - **Бўш қатор қўшиш** → ном ёзинг → QR тайёр. Кейин ўша қатордаги **PDF юклаш** тугмасини босасиз.
4. Ҳар бир қатор ёнида ўз QR-коди кўринади.
5. **Телефон камераси** билан QR-ни сканер қилинг → viewer саҳифада ўша PDF очилади.
6. Телефонда катталаштириш ва "Юклаб олиш" ишлайди. Админ панель кўринмайди.

## 8. QR-кодни босмага бериш

Ҳар бир қатордаги **QR юклаш** тугмаси QR-ни PNG расм (600×600) қилиб беради — визитка, эълон ёки маълумотномага босиш учун етарли сифат.

PDF'ни кейинчалик янгиласангиз (**PDF алмаштириш**), босилган QR-кодни қайта чиқариш шарт эмас — ўша QR янги PDF'ни очаверади.

## Эслатмалар

- Бир мартада 10 тагача PDF, ҳар бири 20 MB гача.
- QR очиқ: паролсиз ҳар ким кўра олади (талаб шундай эди). PDF манзили тасодифий 10 белгили ID — тахмин қилиб топиш амалда мумкин эмас.
- PDF ўчирилса, унинг QR-коди ҳам ишламай қолади — "Маълумотнома топилмади" деб чиқади.
- Компьютерда синаб кўриш: `npm install` → `ADMIN_PASSWORD=123 npm start` → `http://localhost:3000`
